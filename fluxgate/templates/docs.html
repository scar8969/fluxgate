API Documentation

FluxGate exposes a JSON API for clients, backends, and admins.

Authentication

Backend endpoints use the X-API-Token header. Admin endpoints require an admin session cookie.

Public endpoints

MethodPathDescription
GET/api/subscribe?token=<id>&sub_type=ssSubscription links (ss/v2ray/trojan/clash)
GET/api/subscribe/qr?token=<id>&sub_type=ssQR code PNG of the subscription URL
GET/api/proxy_configs/<node_id>Node config for backends (X-API-Token)
POST/api/proxy_configs/<node_id>Traffic report + heartbeat (X-API-Token)
GET/api/metricsPrometheus metrics
GET/api/docsThis page

User endpoints (session)

MethodPathDescription
POST/api/user/settingsChange ss password
GET/api/user/stats/traffic_chart7-day traffic chart data
GET/api/user/stats/ref_chartReferral chart data
POST/api/checkinDaily check-in reward
POST/api/ordersCreate order (body: goods_id)
POST/api/callback/alipayPayment callback (body: out_trade_no)
POST/api/gen/invitecodeGenerate invite codes

Admin endpoints (admin session)

MethodPathDescription
GET/api/system_statusUsers/orders/revenue/online nodes
GET/api/admin/analytics?days=14Revenue + signup trends
GET/api/admin/export/usersCSV of users
GET/api/admin/export/ordersCSV of orders
POST/api/admin/nodesAdd node
DELETE/api/admin/nodes/<id>Delete node
POST/api/admin/nodes/<id>/toggleEnable/disable node
POST/api/admin/goodsAdd goods
DELETE/api/admin/goods/<id>Delete goods
POST/api/admin/users/<id>/toggleEnable/disable user
POST/api/admin/users/<id>/reset_trafficReset user traffic

Example: backend traffic report

curl -X POST http://localhost:5000/api/proxy_configs/1 \ -H "X-API-Token: dev-api-token" \ -H "Content-Type: application/json" \ -d '{"data":[{"user_id":2,"upload":1048576,"download":2097152}]}'

Webhooks

Set WEBHOOK_URL to receive order.paid events on every completed payment.
